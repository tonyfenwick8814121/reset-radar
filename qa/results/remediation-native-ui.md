# 修复后原生 UI 观察 · 2026-09-09

环境：macOS 26.6.2 / Apple Silicon。使用临时构建的 `Reset Radar Audit Manual.app`，注入临时存储和空提醒调度器；不读取或改写用户数据，不申请系统通知权限。

1. 手动重置机会以绿色“手动重置机会 · 距失效”显示。倒计时从约 20 秒自然归零后，主窗立即回到“暂无重置预告”，历史显示“手动机会 · 已失效”。
2. 自动重置以珊瑚红“发现额度重置预告”显示。归零后变为金色“到达预计时间 · 等待确认”；展开详情点击“确认已重置”后回到监测，历史显示“自动重置 · 已确认”。
3. 英文 100 小时显示 `100:00:01`，未出现中文“天”或天数单位。切换迷你窗后倒计时继续使用累计小时。
4. 迷你窗保留事件状态；从屏幕右上方展开时主窗完整钳制在可见区域，没有越过屏幕右边界。双击迷你窗可展开。
5. 手动录入窗口可选择“自动重置预告 / 手动重置机会”，填写原文或链接、失效开关与时间、时区、产品和适用人群。保存带一小时有效期的手动机会后，主窗显示“距失效”、来源链接、“标记已使用”和“不再显示”。

本轮没有测试真实系统通知送达、睡眠、外接屏或正式签名安装；这些边界保留在 `docs/REMEDIATION_REPORT.md`。
