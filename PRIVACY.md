# Privacy

Reset Radar reads public RSS and Atom feeds directly from the listed providers. It does not require an X account, OpenAI account, API key, analytics SDK, or advertising identifier.

Preferences, parsed events, source health, and notification bookkeeping stay in `~/Library/Application Support/ResetRadar/`. The app does not upload that local state. Removing the application does not automatically remove this folder.

Opening a source link uses the default browser and is then subject to that website's privacy policy. Public feed providers can observe ordinary network metadata such as the request IP address and user agent.
