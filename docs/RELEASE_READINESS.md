# 0.2.1 试用与发布准备

核查日期：2026-09-09。源码已公开；应用目前适合熟人内测，尚未达到普通用户正式发行的门槛。

## 0.2.1 声音规则

- 查询完成、失败、重复公告、含糊线索、历史完成和取消公告静音。
- 合并完本轮所有来源后，只为新发现的有效自动重置预告或可用手动机会响铃；有效时间或适用范围的重要更正可再提醒一次。一轮最多响一次。
- 提前 30/5 分钟和到点系统通知改为无声，已有声音通知在启动协调时替换。
- 用户关闭声音后发现提醒也静音；主动“试听”仍可播放。
- 已使用、忽略、确认完成、取消和归档的事件不会因为订阅重放重新变为活跃。

## 证据

- 54 项项目测试通过（警告作为错误），包括普通查询、失败、旧完成消息、含糊线索、过期/尚未发放的机会、重复查询、同轮撤销、处理后重放、重启和时间更正。
- 26 项独立验收在临时源码副本中全部通过。0.2.1 ZIP 解出内容与构建应用逐文件一致；去除签名后的 Release 可执行文件与包内程序一致。
- 本机已安装 0.2.1（build 3），原生“立即查询”完成后仍为“暂无重置预告”，四源成功。此项验证 UI/查询链路，静音触发策略由回归测试和声音调用路径检查验证，未录制系统音频。
- 测试通过说明已覆盖场景的行为符合预期，不代表真实世界所有公告均能正确识别。
- 当前钥匙串没有有效代码签名身份；已安装 0.2.0 的 `spctl --assess --type execute` 返回 rejected。0.2.1 仍为临时签名，不宣称已解决此安装限制。

## 朋友试用

现有 ZIP 适用于 Apple Silicon Mac（M 系列）；最低系统声明为 macOS 14，当前实际验证机为 macOS 26.6.2。Intel Mac 和 macOS 14/15 尚未验证。

安装包不包含用户事件、设置或账户凭据。收件人解压后将应用拖到 Applications；下载的临时签名应用可能被 Gatekeeper 拦截。愿意测试且确认来源可信的收件人，可参考 Apple 的[手动允许打开说明](https://support.apple.com/en-gb/102445)。不要关闭系统全局安全保护。此流程尚未在朋友的干净机器上验证，因此不能承诺直接双击即可安装。

## 正式公开发行的优先事项

1. Developer ID 签名、公证、附加公证票据，并在另一台 Mac 下载、安装、启动验证。[Apple 公证说明](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)
2. 实测真实系统通知送达、权限拒绝/恢复、睡眠唤醒、断网重连及正常退出；当前注入调度器测试不能替代真实送达测试。
3. 强化来源可靠性与误报控制：完成消息与预告的精确关联、多来源时间冲突的长期保持、原文发布与转引时间的区分、产品及套餐适用性；以真实公告样本回放检验。
4. 准备版本说明、安装指引及后续升级路径。无须先加入自动更新服务才能内测。

签名公证解决分发体验，不保证来源覆盖完整或个人额度适用。需要达到上述门槛后再创建面向普通用户的正式 GitHub Release。
