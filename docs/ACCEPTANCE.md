## 真机交互与独立运行

- 首次启动无需额外点击即显示主窗；首次适用新预告出现时在交互屏幕中央，普通应用前方，当前输入焦点不跳走。
- 普通桌面、第二 Space、另一个应用全屏、Stage Manager、多屏和屏幕拔插逐项记录实际效果；不把系统安全界面列为可覆盖目标。
- 大窗拖动、右上角收起、迷你拖动、展开、隐藏、关闭窗口、菜单栏恢复、退出均按 PRD 执行；关闭视图后监测继续，退出后停止。
- 目标日期和最近查询时间在主窗可见；迷你窗保留目标日期时间，健康详情可打开。
- 静音、音量、试听、通知未授权、专注模式和免打扰均可理解；新公告单次短音，无循环。
- 默认中文和北京时间，英文无残留中文业务文案，所有系统时区可选。VoiceOver 有按钮标签，降低透明度/减少动画可用。
- 睡眠 10 分钟、断网 10 分钟、系统时钟调整、跨午夜均不累计计时误差；恢复时有正确状态。
- 关闭并更新 Codex 后仍监测夹具和真实来源；Reset Radar 无 Codex 进程、端口、内部文件依赖。
- 无 X 账号、密钥或登录浏览器仍能读取四个公开源；分别记录真实状态。社区订阅成功不能显示“官方完整覆盖”，无上游健康字段时明确未知。
- 默认折叠：单位标签不存在，语言双段按钮、目标时间与查询状态可见；底部箭头展开/收起详情，aria-expanded 与可访问内容一致，折叠详情不能 Tab 到。
- 琥珀预告、珊瑚红临近重置、绿色重置机会和灰色等待在浅/深色下明显可分；去掉颜色后仍能通过文字与图标区分。失败标记不抹掉事件。
- 中 / EN 在主窗和迷你窗内均可直接操作，语言/时区切换不改变 UTC 或折叠状态。
- macOS 26+ 原生 Liquid Glass、14/15 毛玻璃回退、降低透明度实色、减少动态效果分别真机检查；不以 CSS 截图证明原生效果。
