## 首个交付切片：M0–M1

1. 建立能编译启动的原生项目和菜单栏入口，做出跨普通桌面的 NSPanel；在当前 SDK 上验证玻璃 API，保留旧系统回退。
2. 读取 ModelYard RSS、Codex Reset Atom 和两个官方 RSS，分别记录可达性、缓存、原文完整度与上游健康是否可知。重点比较社区源对同一原帖的覆盖差异。
3. 跑通单条确定时间夹具：解析 → UTC → 本地日期时间 → 本地倒计时 → 一次提醒 → 折叠/迷你/隐藏恢复 → 保存 → 重启。
4. 初次历史导入静默建基线，只有明确未来且仍适用的事件可以主动提示；不把过去公告当新消息。
5. 保留真实源与夹具的明确标记；来源不可靠时照常完成窗口/计时模块，并如实显示覆盖限制。

免费订阅的完整性、提前量以及全屏窗口行为仍需实测。这是 M0 的工作，不是继续讨论 UI 或暂停所有开发的理由。
